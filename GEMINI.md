# wp-dev-skills — WordPress Plugin Development Skills

This extension provides WordPress plugin development skills. Skills are
loaded on demand when you describe a task — you do not need to name them
explicitly.

## Available skills

| Skill | Activates when |
|---|---|
| `wp-github-flow` | Shipping commits/branches/PRs, debugging GitHub issues, conventional commits |
| `wp-woocommerce` | WooCommerce extensions — gateways, shipping, REST API, HPOS, cart/checkout blocks |
| `wp-plugin-testing` | PHPUnit, Brain\Monkey, WP_Mock, Codeception, redirect harness, CI test setup |
| `wp-coding-standards` | PHPCS/WPCS setup, phpcs.xml config, sniff violations, PHPCS in CI |
| `wp-ci-qa` | PR has QA failures or "Testing Failed" label — root-cause, fix, re-test comment |
| `wp-phpstan-stubs` | Scaffold a PHPStan stubs package for a third-party plugin/library |
| `wp-build-tools` | @wordpress/scripts, webpack, Vite, .asset.php enqueuing, Sass/PostCSS |
| `wp-background-processing` | Action Scheduler, WP_Background_Process, WP Cron, batch jobs |
| `wp-multisite` | Network activation, network admin, per-site vs network options, switch_to_blog() |
| `wp-i18n-workflow` | POT/PO/MO generation, JS translations, translate.wordpress.org pipeline |
| `wp-database` | dbDelta schema, versioned migrations, $wpdb CRUD, query optimisation |
| `wp-email-templates` | HTML transactional emails, branded base wrapper, wp_mail() integration |
| `wp-freemius` | Freemius SDK bootstrap, feature gating, license management, pricing page |
| `wp-plugin-audit` | Consistency audit — version drift, naming/prefix, docs↔code mismatch |
| `wp-plugin-release` | Version bump — sync header/constant/readme.txt/changelog coherently |
| `wp-org-submission` | WP.org plugin directory submission, SVN deploy, rejection pattern fixes |
| `wp-admin-browser` | WordPress admin automation via Chrome DevTools MCP |
| `wp-guided-tour` | Driver.js guided tours in WordPress admin — setup, PHP config, JS scope |
